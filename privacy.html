Privacy Policy

JARVIS Operator · last updated 27 September 2026

JARVIS Operator is personal software run by one individual on their own computer. It has a single user — its owner — and is not offered to anyone else. This policy describes what happens to Google user data when the owner connects their own Google Account.

Where the data goes

Nowhere. Data retrieved from Google is held on the owner's own computer, inside an encrypted volume, and is used only to answer the owner's own questions. Specifically:

  • There is no server, no hosted database and no user accounts.
  • The data is not sold, not shared, and not transferred to any third party.
  • It is not used for advertising, profiling or analytics.
  • It is not used to train any machine-learning model.

One exception, stated plainly. To phrase an answer in natural language, a short excerpt of the relevant text may be sent to a third-party language-model provider (Google Gemini). Only the fragment needed to answer the current question is sent, it is not retained by this application, and the owner can turn this off and use a local model instead, in which case nothing leaves the machine at all.

Limited Use

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Cached Google data is kept only as long as it is useful to the owner and can be deleted by them at any time by removing the local files. Authorisation can be revoked at any moment from the owner's Google Account permissions page, which immediately ends this application's access.

Security

The stored data sits in an encrypted volume on the owner's machine, unlocked with a hardware security key. Credentials are kept outside the application's source code and are not published.

Children

This application is not offered to the public and is not directed at anyone. It is used only by its owner, on the owner's own account and data.

Changes

If this policy changes, the revised version will be posted at this address with an updated date.

Contact

Enquiries can be sent to the developer contact address registered on the Google Cloud project for this application.
