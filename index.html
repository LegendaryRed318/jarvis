JARVIS Operator

A personal voice assistant that runs on one laptop, for one person.

JARVIS Operator is a self-hosted assistant built and used by a single individual. It runs locally on the owner's own computer. It is not a commercial product, it is not distributed, and it has no users other than its owner.

What it does

It answers questions about the owner's own notes, tasks, calendar and files; reads those records directly rather than guessing at them; and can draft replies for the owner to send themselves. It runs on local hardware, with cloud language models used only to phrase answers.

Why it asks for Google access

With the owner's permission it reads a small amount of Google data so it can answer questions about the owner's own day:

  • Gmail — to summarise unread mail and prepare replies. The app can send a message, but only one the owner has explicitly confirmed; it never sends on its own initiative.
  • Calendar — to read upcoming events, and to add a reminder when the owner asks for one.
  • Google Slides — to build a deck in the owner's own account when asked.
  • Drive — to find the owner's own documents by name. Read only.
  • Contacts — to match a name the owner says to the right person. Read only.

In short

All of this data stays on the owner's own machine, inside an encrypted volume. None of it is sold, shared, or sent to any third party. There is no server, no account system and no analytics.
